C Klausur-Master-Lernzettel

1. Grundlagen & Konventionen

  • Compiler-Phasen: Präprozessor (#) → Compiler (C zu Assembler) → Linker (verbindet Libs).
  • Naming (DHBW Standard):
    • camelCase: Variablen, Parameter, Funktionen.
    • PascalCase: typedef-Namen, struct, union, enum.
    • UPPER_SNAKE: Konstanten & Makros.

2. Variablen & Datentypen

Floating Point (IEEE 754)

Ein float (32 Bit) besteht aus: 1 Bit Vorzeichen | 8 Bit Exponent (mit Bias 127) | 23 Bit Mantisse.

Typecasting

  • Implizit: Automatisch von "kleineren" zu "größeren" Typen (z.B. int zu double).
  • Explizit: Manuell erzwungen durch (Typ)Variable.
    Beispiel: float avg = (float)sum / count;

Definition vs. Deklaration vs. Initialisierung

  • Deklaration: "Es gibt eine Variable namens x" (z.B. extern int x;).
  • Definition: Speicher wird reserviert (z.B. int x;).
  • Initialisierung: Erster Wert bei Definition (z.B. int x = 5;).

3. Komplexe Typen: Struct, Union, Typedef

Struct vs. Union

  • Struct: Jeder Member hat eigenen Speicherplatz.
  • Union: Alle Member teilen sich den gleichen Speicherplatz. Nur ein Member gleichzeitig nutzbar.

Typedef

Erstellt einen Alias-Namen:

typedef struct {
    int id;
} Student; // Nutze 'Student' statt 'struct Student'

5. Strings & strcpy

Strings sind in C char-Arrays mit \0 am Ende. Zuweisung nach Deklaration geht nur via Funktion:

#include <string.h>
char ziel[20];
// ziel = "Test"; // FALSCH
strcpy(ziel, "Test"); // RICHTIG

6. Dynamische Speicherverwaltung (Heap)

  • malloc(size): Reserviert Speicher (Inhalt undefiniert).
  • calloc(n, size): Reserviert Speicher und setzt ihn auf 0.
  • free(ptr): Muss aufgerufen werden, um Memory Leaks zu vermeiden.

7. Variadic Functions

Funktionen mit variabler Anzahl an Argumenten (wie printf).

#include <stdarg.h>
void funk(int fest, ...) {
    va_list args;
    va_start(args, fest);
    int x = va_arg(args, int); // Typ holen
    va_end(args);
}

8. Kontrollstrukturen

  • switch(var): Nur für ganzzahlige Typen (int, char). break verhindert "Fall-Through".
  • do-while: Die einzige Schleife, die garantiert mindestens einmal läuft.
