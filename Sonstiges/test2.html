Strings
Warum liefert char s[] = "Hi"; printf("%d", (int)sizeof(s)); den Wert 3 zurück, obwohl "Hi" nur zwei Buchstaben hat?
Antwort anzeigen
C fügt automatisch das Null-Terminierungszeichen \0 am Ende eines String-Literals hinzu. Der Speicher sieht so aus: 'H', 'i', '\0'. Das sind 3 Bytes.
Speicherverwaltung
Was passiert, wenn du 100x malloc() in einer Schleife aufrufst, aber nie free()?
Antwort anzeigen
Es entsteht ein Memory Leak. Dein Programm verbraucht immer mehr Arbeitsspeicher, ohne ihn zurückzugeben. Irgendwann liefert malloc nur noch NULL zurück oder das System wird extrem langsam und beendet dein Programm.
Strukturen
Was ist der Vorteil von typedef struct { ... } Node; gegenüber einer normalen struct Node { ... };?
Antwort anzeigen
Mit typedef kannst du Variablen einfach mit Node n; deklarieren. Ohne typedef müsstest du jedes Mal das Wort struct mitschreiben: struct Node n;. Es macht den Code also kürzer und lesbarer.
Pointer
Wann schreibst du p->wert statt p.wert?
Antwort anzeigen
Den Pfeil -> nutzt du immer dann, wenn p ein Pointer auf eine Struktur ist. Den Punkt . nutzt du, wenn p die Struktur-Variable selbst ist.
Unions
Wie viel Speicher belegt diese Union? 
union Test {
    char c;    // 1 Byte
    int i;     // 4 Byte
    double d;  // 8 Byte
};
Antwort anzeigen
8 Byte. Eine Union belegt immer nur so viel Platz wie ihr größtes Element, da sich alle Member denselben Speicherbereich teilen.
Funktionen
Welche Header-Datei und welches Makro brauchst du, um das erste variable Argument in einer Variadic Function zu lesen?
Antwort anzeigen
Du brauchst #include <stdarg.h>. Mit va_start initialisierst du die Liste und mit va_arg(args, typ) liest du das Argument aus.
